Type in a BASIC listing

Keys are pressed on the emulated keyboard one by one. Click the picture to type yourself: RUN/STOP = Esc, C= = Left Alt, £ = Backquote, RESTORE = Page Up.
On the Commodore 2002, click the door under the screen for its controls, and its power button to switch the monitor on and off. Settings > Display switches to a flat panel.

Commodore ROMs needed

The emulator runs Commodore's original firmware: BASIC, the KERNAL, the character set and the 1541 disk drive's DOS. It can't come with this page, so it is set up once and kept in this browser only.

Automatically: the page rebuilds each ROM from public disassemblies and checks it against the real chip. Yourself: give a ROM file, or a file or web address of a disassembly or hex dump.

Settings

Changing the video standard restarts the machine (the disk is kept). Emulation is always cycle-exact; "as fast as possible" only removes the pacing.

Brightness, contrast, colour, tint, position and hold: the knobs behind the 2002's door (click the door under the screen).

Picture tube

Switching the SID chip resets its registers; a tune that is playing may need restarting. The main volume is the slider in the top bar (all the way left = muted).

On a real 1541 the number is set by cutting jumper pads inside the drive. Use it in commands: LOAD"$",9. Changing it restarts the machine.

Each ROM type can have several images; the selected one is used. Changes restart the machine.
